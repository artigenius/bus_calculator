# Четыре самостоятельных калькулятора Changellenge >>

Каждый HTML-файл открывает сразу свой калькулятор. Общего экрана выбора и переходов между калькуляторами нет.

| Калькулятор | Файл / путь на сайте |
|---|---|
| Стажировки | `internship.html` |
| Марафон роста / внутренний кейс-чемпионат | `growth.html` |
| EVP (активация) | `evp.html` |
| Кейс-чемпионаты Changellenge >> | `championship.html` |

## Как пользоваться сейчас

Откройте нужный HTML-файл двойным щелчком в Finder. Если он открывается в редакторе, выберите «Открыть в программе» → Safari или Google Chrome. Интернет и запуск сервера не нужны. JavaScript в браузере должен быть включён.

Каждый файл содержит свою модель, оформление, шрифты и логотип. Его можно копировать в любую папку, переименовывать и отправлять отдельно — другие файлы проекта ему не нужны. При обновлении страницы восстанавливаются исходные значения, как и в прежней версии.

Архив `calculators-standalone.zip` содержит только четыре готовых HTML-файла и краткую инструкцию.

## Адреса в интернете

Страницы пока не опубликованы в интернете. Для публичных адресов загрузите четыре HTML-файла на свой статический хостинг или передайте администратору сайта. Если файлы лежат в одной папке сайта, адреса заканчиваются на `/internship.html`, `/growth.html`, `/evp.html`, `/championship.html`. Каждый адрес открывается напрямую и не требует главной страницы, маршрутизатора или настроек перенаправления на index.html.

Можно разместить каждый файл на отдельном сайте, переименовав его в `index.html`. Тогда у каждого калькулятора будет свой домен или поддомен. Домен определяется выбранным хостингом.

Старый `calculator.html` оставлен только для совместимости: он перенаправляет на «Стажировки». Для использования и публикации четырёх страниц он не нужен.

## Изменения в коде

- `src/calculator.template.html` — общий исходный шаблон оформления и интерфейса; не предназначен для непосредственного открытия.
- `src/products/*.js` — четыре раздельные модели. Формулы и исходные значения перенесены без изменений.
- `scripts/build_pages.py` — сборка четырёх автономных HTML-файлов; достаточно Python 3, дополнительные библиотеки не нужны.
- `scripts/verify_pages.cjs` — актуальная проверка через Playwright: прямой вход через файл и HTTP, эталонные расчёты, изменение полей, сброс, раскрытие деталей, перезагрузка, мобильная ширина и отсутствие внешних запросов.

После правок исходников выполните:

```sh
python3 scripts/build_pages.py
```

Для проверки, если установлены Node.js, Playwright и Chromium:

```sh
node scripts/verify_pages.cjs
```

При необходимости укажите путь к браузеру в `CHROME_PATH`, а к установленному модулю Playwright — через `NODE_PATH`.

Старые `scripts/verify*.py` и документация в `docs/project-history.md` относятся к предыдущей версии с общим экраном и сохранены как история. Для новой версии используйте `verify_pages.cjs`.

Исходные Excel-модели и материалы бренда сохранены в `source_files/` и `brand_assets/`.
